# Denuncia pública: resalto de la Parroquia El Divino Niño

Página ciudadana (PWA) para denunciar el resalto construido en plena esquina, junto al sumidero de la Parroquia El Divino Niño, barrio Colinas del Portal, Caucasia (Antioquia).

## Qué hace
- Muestra el video y las fotos de la obra (25 de septiembre de 2026).
- Ficha del resalto: ubicación, drenaje, señalización, acto administrativo, estudio y consulta.
- Norma aplicable: Ley 769 de 2002 (arts. 74 y 120), Manual de Señalización Vial (Res. 20243040045005 de 2024) y Ley 1755 de 2015.
- Recoge firmas por WhatsApp, comparte la denuncia y arma un derecho de petición listo para radicar.
- Aviso de privacidad según Ley 1581 de 2012. No guarda datos personales.

## Publicar en GitHub Pages
1. Crear el repositorio `haroldco45/resalto-divino-nino`.
2. Subir todos los archivos de esta carpeta a la raíz.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Queda en `https://haroldco45.github.io/resalto-divino-nino/` (las etiquetas OG ya apuntan ahí).
